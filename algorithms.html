Popular Machine Learning Algorithms

An algorithm is a method used to learn patterns from training data. Different algorithms are suited to different tasks.

Linear Regression

Predicts a numeric value by fitting a linear relationship between inputs and an outcome. Example: estimating a house price.

Decision Tree

Makes predictions through a series of branching questions. Its rules can often be visualized and explained.

Random Forest

Combines predictions from many decision trees to improve stability and often predictive performance.

Neural Networks

Use connected layers of computational units to learn complex patterns, including patterns in images and text.

How do we evaluate a model?

We train a model on training data and evaluate it on separate test data. For classification tasks, useful measures include accuracy, precision, recall, and F1 score. No single metric is best for every problem.
